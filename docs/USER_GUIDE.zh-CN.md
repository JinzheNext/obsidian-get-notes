# Get Notes 使用指南

这是一份给普通用户看的快速说明。如果你只是想把 Get 笔记同步进 Obsidian，优先看这里。

## 这是什么

`Get Notes` 是一个 Obsidian 桌面插件，用来把 Get 笔记同步到你的 Vault。

它支持两种同步方式：

- `API 模式`
  适合已经开通 Get OpenAPI 的用户，通常更完整、更稳定。
- `普通登录模式`
  适合没有 API Key 的用户，通过 Get 官方网页导出同步。

不管你用哪种模式，插件最终都会把结果写入同一套目录。

## 安装

1. 下载 release 中的 `main.js`、`manifest.json`、`styles.css`
2. 在你的 Vault 中创建目录：
   `.obsidian/plugins/obsidian-get-notes`
3. 把这 3 个文件放进去
4. 重启 Obsidian
5. 在“社区插件”里启用 `Get Notes`

## 推荐你怎么选

### 如果你有 API Key

优先用 `API 模式`。

原因：

- 音频和会议类内容通常更完整
- 增量同步体验更好
- 长期使用更稳定

### 如果你没有 API Key

用 `普通登录模式`。

你需要知道：

- 首次同步可能比较慢
- Get 官方导出包可能很大
- 更适合低频同步、导入或备份

## 第一次配置

### API 模式

1. 打开插件设置
2. 选择 `API 模式`
3. 填写 `API Key`
4. 填写 `Client ID`
5. 点击 `测试连接`
6. 点击 `立即同步`

### 普通登录模式

1. 打开插件设置
2. 选择 `普通登录模式`
3. 点击 `打开普通登录`
4. 在网页中登录 Get
5. 回到 Obsidian
6. 点击 `立即同步`

## 同步后会写到哪里

默认目录：

`00_Inbox/020 GetNotes`

目录结构：

```text
00_Inbox/020 GetNotes/
  01 语音记录/
  02 多人会议/
  03 纯文本记录/
  04 链接同步摘抄/
  99 其他/
  _assets/
```

## 你最可能关心的几个问题

### 1. 为什么普通登录模式慢很多？

因为它依赖官方网页导出，导出 ZIP 可能很大。插件通常要先下载，再解压，再重建 Markdown。

### 2. 为什么普通登录模式有时内容不如 API 完整？

因为 Get 官方导出的 HTML 本身有时就不包含和 API 一样完整的正文，尤其是会议和音频类笔记。

### 3. 如果我手动删掉一篇同步笔记，会不会又被恢复？

不会。

插件会把这类情况记为“用户主动删除”，后续不会自动恢复。

### 4. 我可以先用普通登录模式，以后再换 API 模式吗？

可以。

插件会尽量把两种模式对齐到同一套落表结构，而不是生成两套独立知识库。

### 5. 插件会不会乱改我自己的文件？

不会。

插件只会管理它自己同步出来的 Markdown 和附件。

## 推荐使用习惯

- 有 API Key：把 `API 模式` 当主力同步方式
- 没 API Key：把 `普通登录模式` 当低频同步或备份导入方式
- 普通登录模式建议不要太高频，间隔拉长一些更稳
- 如果你已经手动整理过某篇笔记，删除它前先确认你是否还希望插件继续追踪

## 出问题时先看哪里

1. 插件设置页里的最近同步结果
2. 目标目录下是否已经生成新的 Markdown
3. `.obsidian/plugins/obsidian-get-notes/reports/migration-report.json`

## 一句话建议

如果你能申请 API，就优先用 `API 模式`。

如果你没有 API，也可以直接用 `普通登录模式` 开始，只是它更像“兼容导入 + 低频同步”，不要把它期待成和 API 完全等价。
